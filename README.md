# 澄屿 · 3D 生态水族箱

> 一方会自己长大的水下世界。

纯前端的淡水生态模拟：Three.js 实时渲染一缸会呼吸的水，鱼会进食、长大、繁殖、生病、衰老，
水草会光合产氧，硝化系统会把鱼便转成硝酸盐。没有后端、没有构建步骤，`index.html` 打开就能玩。

## 玩法要点

**生态是真的在跑**

- 氮循环：鱼便与残饵 → 氨氮 → 硝化菌 → 硝酸盐 → 水草吸收 / 换水移出
- 光照驱动光合作用：白天产氧，夜里耗氧；强光 + 高硝酸盐会爆藻
- 溶氧不足鱼会浮头，温差与水质骤变会让鱼应激、生病，拖久了会死亡

**鱼是有个体差异的**

- 27 种观赏鱼（含色型 / 鳍型变体共 59 种可选）、7 种水草、4 种螺虾，各有分层（上层 / 中层 / 底层）、食性、领地性、耐温与耐污能力
- 每条鱼有独立体型、年龄、健康度；吃得饱、水质好会繁殖，老了会游得慢、颜色变淡
- 分层决定喂食策略：浮料给上层鱼，沉料给底层鱼，螺虾和鼠鱼负责清残饵

**养得好也能卖得好**

- 详情卡给实时估价：品种基准价 × 体型 × 年龄阶段 × 健康 × 生病折损 × 当季行情
- 春季繁殖季最贵，冬季最便宜；老鱼贬值，病鱼卖不上价

**布景可以很细**

- 缸体 30–200cm 长、20–80cm 宽高自由组合，换缸会改变水体容量与画面比例
- 底砂材质与地形坡度、石头的形状 / 颜色 / 大小 / 数量、水草逐件拖动摆位
- 一键造景模板（构图 + 落位一起套），之后还能在「布景摆位」里微调

**挂机也能养**

- 自动化管家：定时喂食、定时换水、自动擦藻、日照时段开关灯、缺氧自动打氧、发现病鱼自动下药
- 时间可 1× / 4× / 16× 快进（1× 下约 72 秒现实时间过一天）

**其他**

- 商店与图鉴支持中文、全拼、首字母、英文与拉丁名搜索（零依赖自带词表）
- 3D 图鉴可拖动旋转查看，鱼有不同色型与鳍型
- 存档写在 localStorage，可导出为文件

## 快速开始

### 方式一：本地静态服务（推荐）

```bash
npm run serve          # 零依赖，默认 http://localhost:8080
```

任何静态服务器都等价：

```bash
python -m http.server 8080
```

### 方式二：直接双击 `index.html`

也能跑，但 `file://` 下浏览器不允许读取 GLB，页面会退回 `js/models/*.js` 内嵌包。
内嵌包不入库（约 98MB 生成物），需要先构建一次：

```bash
npm run build:models   # 把 models/*.glb 拆成 js/models/<名字>.js
```

都没有时页面仍可用——渲染层会回退到程序化生成的几何模型。

### 校验资源一致性

```bash
npm run verify
```

检查模型文件、内嵌包清单、缩略图、造景模板、水草轴向、顶点法线、拼音覆盖率。

## 项目结构

```
aquarium/
├── index.html              页面骨架与各个弹层（设置 / 玩法 / 图鉴 / 确认框）
├── style.css               全部样式
├── js/
│   ├── species.js          物种资料库：参数、外观、模型绑定（数据层）
│   ├── sim.js              模拟引擎：时间、氮循环、生长繁殖、疾病、经济
│   ├── render.js           Three.js 场景：鱼群动画、水草、底砂、光影、拾取
│   ├── app.js              界面与交互：商店、图鉴、侧栏、设置、存档
│   ├── pinyin.js           轻量拼音检索（自带词表，零依赖）
│   └── models.js           模型清单索引（由 build-models.js 生成）
├── models/
│   ├── *.glb               写实模型（鱼带骨骼与游动动画）
│   └── thumbs/*.png        列表用预渲染缩略图
├── vendor/                 three.js r149 + GLTFLoader + SkeletonUtils
├── tools/                  资产流水线与校验脚本（Python / Node）
│   ├── serve.js            本地静态服务器
│   ├── build-models.js     生成 base64 内嵌包
│   ├── verify_assets.js    资源一致性门禁
│   └── blender/            Blender 程序化建模脚本
└── docs/                   设计与迭代文档
```

## 技术实现

| 模块 | 职责 | 要点 |
| --- | --- | --- |
| `species.js` | 物种数据 | 归一化分层坐标、食性、耐温、生长曲线、繁殖方式、外观与模型绑定 |
| `sim.js` | 生态模拟 | 固定步长推进；氨氮/亚硝酸盐/硝酸盐三态、溶氧、藻类、季节行情 |
| `render.js` | 实时渲染 | 1 厘米对应世界单位由缸宽动态推导，鱼在任何缸里都保持真实比例 |
| `app.js` | UI | DOM diff 式局部刷新，避免每帧重建列表导致输入失焦 |
| `pinyin.js` | 搜索 | 汉字 → 无声调拼音 + 首字母双索引，命中率由 `verify_pinyin.js` 校验 |

**模型三级加载**（`render.js`）

1. `http(s)`：直接按 URL 加载 `models/<名字>.glb?v=<版本号>`
2. `file://` 或 URL 失败：注入 `js/models/<名字>.js` 并解码 base64
3. 都不行：回退到程序化生成的几何模型

每条鱼一个独立脚本，首屏只加载真正用到的模型。

## 3D 资产管线

模型来自 AI 生成（混元 3D 等）与 Blender 程序化建模两条路，最终都收敛到同一条接入流程：

```
gen_hunyuan.py / blender/*.py   生成或导出原始 GLB
        ↓
pack_model.py                   压贴图（法线图无损，基础色 JPEG，丢掉无效粗糙度图）
        ↓
rig_fish.py                     烘焙 Z-up→Y-up、绑 9 节脊椎 + 3 根鳍骨
        ↓
add_turn_clip.py                生成大摆幅 Turn 游动片段
        ↓
check_skin.py                   蒙皮闸门：按 glTF 规则离线验证姿态包围盒
        ↓
ingest.py                       校验 → 压缩 → 绑骨 → 挂到 species.js → 重建内嵌包
        ↓
make_thumbs.py                  预渲染 176×120 缩略图，避免前端离屏渲染卡主线程
```

想接入自己的模型：

```bash
python tools/ingest.py <模型.glb> <品种id> --name 显示名
```

`ingest.py` 不关心模型来自哪家服务，走这一条就能进缸。

## 说明与边界

- **这是一个简化模型**：参数为可玩性与教学直观做过压缩，不能当作真实饲养的精确处方。
- **模型不是照片扫描资产**：均为程序化生成或 AI 生成的写实风格几何，非实物扫描。
- **数据全部在本机**：存档写 localStorage，不上传任何服务器。
